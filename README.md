# Content Hub

A platform for content production, generation, approval, publication and analytics.

Backend: Elysia.js + Bun + TypeScript. 
Frontend: Solid.js + TanStack Solid Router.
Workers: Python and other runtimes, each in its own workspace.

## Structure

```text
├── .husky/                 # hook entry points, generated by `bun run setup`
├── configs/
│   └── typescript/         # @configs/typescript — shared tsconfig presets
├── docs/
│   └── configs/            # one page per config package
├── packages/
├── .gitattributes          # git line-ending and diff normalization
├── .gitignore              # ignored paths
├── bun.lock                # dependency lockfile (Bun)
├── package.json            # workspace root, pinned toolchain
├── README.md               # THIS FILE
└── turbo.json              # Turborepo pipeline config
```
